# ATLAS Travel Website

A responsive travel-agency concept website built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Landing page
- `destinations.html` — Destination gallery
- `experiences.html` — Travel experience categories
- `about.html` — Brand story
- `contact.html` — Trip enquiry form

## Features
- Responsive layouts using CSS Grid and Flexbox
- Mobile navigation menu
- Contact form validation and demo success message
- External stylesheet and JavaScript
- Photography loaded from Unsplash and fonts from Google Fonts

## Run locally
Open `index.html` in a browser. No build tools required.

## Important
This is a portfolio/demo template. Replace sample copy, contact details, and imagery with the client's approved assets. The enquiry form currently displays a demo confirmation only; it does not send or store submissions. Connect a backend or form service before using it for real bookings.
